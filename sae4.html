SAE 2.03 BUT 1 UE3 — Programmer

Application Web
Django & VM

Contexte & Objectifs

Cette SAE consistait à déployer une application web Django sur une infrastructure virtualisée. L'objectif était de maîtriser toute la chaîne : création de la VM, installation des dépendances, configuration de Django, mise en place de la base de données et exposition du site via Apache en reverse proxy.

  • Déployer une VM Linux pour héberger l'application
  • Installer et configurer Django
  • Mettre en place une base de données relationnelle
  • Exposer l'application via Apache
  • Travailler en collaboration via GitHub

Aperçu du projet

Ce que j'ai réalisé

  • Création et configuration d'une machine virtuelle Linux
  • Installation de l'environnement Python + Django
  • Développement des modèles, vues et templates Django
  • Configuration de la base de données (MySQL/PostgreSQL)
  • Mise en place d'Apache comme reverse proxy pour exposer le site
  • Tests de l'application et correction des bugs
  • Collaboration sur le code via GitHub
