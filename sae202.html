SAE 2.02 BUT 2 UE2 — Connecter

Web Radio avec
Arduino

Contexte & Objectifs

Cette SAE avait pour objectif de concevoir une web radio pilotée via Arduino, accessible et contrôlable depuis un smartphone via Wi-Fi. Ce projet mêle programmation embarquée, protocoles réseau et gestion de flux audio en temps réel.

  • Programmer un microcontrôleur Arduino pour diffuser de l'audio
  • Mettre en place une interface de contrôle via Wi-Fi
  • Gérer la communication entre le smartphone et l'Arduino
  • Documenter le projet et présenter les résultats

Aperçu du projet

Ce que j'ai réalisé

  • Programmation du module ESP32/Arduino en C++ via Arduino IDE
  • Connexion du module au réseau Wi-Fi local
  • Implémentation d'un serveur HTTP embarqué pour l'interface de contrôle
  • Décodage et diffusion de flux audio MP3
  • Interface web accessible depuis un navigateur mobile
  • Tests de stabilité et optimisation de la latence

Compétences acquises

Outils utilisés

Arduino / ESP32 Arduino IDE Wi-Fi / HTTP Flux audio MP3 HTML/CSS (interface)
